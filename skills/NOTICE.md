# Third-party skill attribution

Some skills in this directory are original Gatewright content informed by the
open-source **claude-skills** project (https://github.com/alirezarezvani/claude-skills),
licensed **MIT** (© Alireza Rezvani). Those skills carry `metadata.source: claude-skills-mit`.

The prose here is our own, adapted to Gatewright's format and mission; the concepts
and taxonomy are credited to the upstream project per the MIT license.
